Deviation note: structure and content follow the AW-60964 Figma frame; chat-bubble and accept/outcome colors were remapped onto Lyra status tokens (success/critical/conversation-*) since the source frame mixes legacy SOL hex values not defined in the Lyra token set. The left rail and App Space icon slots are unresolved generic placeholders in the Figma source — both now use the same explicit Lucide set (History, Search, BookUser, CalendarDays, MessageSquareText, ChartBarBig, Inbox, Settings, Ellipsis). States follow the Lyra "Nav-Page" base component from the Figma kit: default (no wash), hover (light gray wash + thin left accent bar), pressed (darker gray wash, same bar); the rail additionally shows a persistent selected state (Inbox, by default) with a light-blue wash, blue left bar, and blue icon, since it's navigation rather than a momentary-action toolbar. The Web Chat/Email tab icons are real vectors extracted from a separate custom "Agent-icons" Figma library (not Lyra's icon set) via Figma's own component data — their brand-specific channel colors (green/pink) are kept as source-exact hex, outside the Lyra token palette by design. Confirm with design before shipping if exact hex parity or specific icon choices are required.
